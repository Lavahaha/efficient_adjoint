# Coupler 边界采样异常分析与修复（2026-11-10）

## 堆栈能确认的原因

报错发生于 `_point_gradient → boundary_sample_points`。前向求解已经返回，
本轮边界点取场和反向求解尚未开始。`[132]` 是本轮完整边界数组中的索引，
不是 CST 网格编号，也不是迭代次数。

采样位置为 `boundary.pts + 0.05 * boundary.normals`，默认高度为
`z=0.0175 mm`。金属厚度为 `0.035 mm`，因此 XY 落进金属时，三维采样点就在
PEC 内部，必须拒绝。默认基板范围为 x∈[-5.6,17.6]、y∈[-7,5.6] mm，
设计区为 x∈[0,12]、y∈[-2.6,0.9] mm；单位法向偏移 0.05 mm 不会越出基板。
在使用默认配置时，这个异常应归入 PEC 碰撞。

本地没有此次失败的 `invalid_boundary_samples.npz`，不能确认索引 132 的
具体坐标和碰撞几何。已经用历史 CAD 复现的同类原因是：

1. `connection_boundary_mask` 只冻结初始金属与固定馈线的接触节点。
2. 轮廓演化后，新接触端点可能通过最近邻活动掩膜检查。
3. 法向来自局部水平集，没有考虑固定馈线；拼接角点上的偏移方向可能进入馈线。

历史例子：边界点 `(12,-2.532822)` 沿法向偏移后变为
`(12.023439,-2.576988)`，进入右侧固定馈线。此前将偏移逐级缩小到
`0.003125 mm` 仍然碰撞，说明仅减小偏移无法修正方向。
原始离线分析见 [历史记录第六节](analysis_summary_2026-11-02.md)。

## 已实施的解决方案

在 `eaopt/runner.py` 的单频直接点采样路径中，以设计区边界与固定几何的交集
识别接触线。固定几何包括模板固定馈线和设计区外保留的初始金属。
只排除距接触线不超过 `1e-9 mm` 的活动点，同步更新 `boundary.active`，
使取场、梯度和速度延拓使用相同标记。拼接角点没有唯一自由表面法向，
此修正避免将其作为独立自由表面点取场；邻近真实可动边缘继续采样。

非接触位置的 PEC 碰撞、基板越界、非法高度和非有限坐标仍然抛异常。
错误文本现在列出 `outside_substrate`、`in_pec`、原边界坐标、法向和请求坐标；
失败 JSON 补充评估编号、高度、偏移和排除索引。正常场快照和失败 NPZ 均记录
`excluded_contact_indices`，其余索引保持原边界数组编号。

## 验证与使用

- `./.venv/python.exe -m unittest discover -s tests -v`：3 项回归测试通过，
  覆盖新接触点、附近可动边缘、缩小设计区后的固定初始金属，以及非接触非法点。
- `./.venv/python.exe tmp/check_single_fd_changes.py`：coupler、divider、antenna
  的初始点采样及既有单频离线检查通过。
- 将 5 组历史运行的 13 个 CAD 状态按 `offset=0.05 mm, z=0.0175 mm`
  重放生产 `boundary_gradient` 路径，全部通过；仅排除 3 个接触点，
  所有初始状态的活动集合保持一致。场数据使用桩函数，不代表新的电磁求解。
  本地结果在 `tmp/coupler_sampling_fix_2026-11-10.json`。

将修复同步到实际运行的代码目录后，使用原命令重新运行即可，无需修改 YAML。
若仍报错，查看新运行目录 `iter_NNN/invalid_boundary_samples.json` 与同名 NPZ，
即可判断索引 132 是否属于另一种碰撞。不要跳过全部非法点或强行将 PEC 内场置零。

网格收敛和最终优化效果的验证。
